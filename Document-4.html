Projet 11 – Questions
1) Le fichier index.html c’est ici où l’on trouvera le code HTML qui est le
“squelette” site. Le fichier style.css c’est ici où l’on trouvera le code CSS
qui sert pour le design du site. Le fichier script.js c’est ici où l’on trouvera
le code JavaScript qui peut être utiliser pour les animations interactives
et tant d’autres.
On peut faire du CSS et JavaScript sur le fichier HTML mais il est
préférable de les faire chacun dans des fichiers séparés pour réussir à se
repérer.
2) La différence entre un id et une class est qu’un id est unique et non
réutilisable tandis qu’une class est réutilisable.
3) L'instruction document.getElementById("message") permet de
récupérer un élément HTML grâce à son identifiant (id).
4) On place la balise <script> à la fin du <body> pour que le HTML soit
chargé avant l'exécution du JavaScript.
5) L'instruction Math.floor(Math.random() * 100) + 1 permet de
générer un nombre entier aléatoire entre 1 et 100 inclus.
